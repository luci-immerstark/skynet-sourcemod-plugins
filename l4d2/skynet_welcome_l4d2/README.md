# SKYNET Welcome

**Left 4 Dead 2** · v1.0 · `skynet_welcome_l4d2.smx`

[Português](#português) · [English](#english) · [Todos os plugins / All plugins](../../README.md)

## Português

Mensagem de boas-vindas no chat, uma vez por conexão.

### O que faz
- Aparece 30 segundos depois de o jogador entrar, só para ele, e lembra o `!join` para quem ficou como espectador.
- Não repete na troca de mapa. Só aparece de novo se o jogador sair e voltar.
- Para mudar o texto, edite as mensagens no `.sp` e compile de novo.

### Requisitos
- SourceMod 1.12 ou mais novo e Metamod:Source
- Left 4 Dead 2

### Instalação
1. Copie a pasta `addons` desta pasta para dentro da pasta do jogo no servidor (`<pasta-do-servidor>/left4dead2/`), juntando com a que já existe.
2. Reinicie o servidor ou digite `sm plugins load skynet_welcome_l4d2` no console.

## English

Welcome message in chat, once per connection.

### What it does
- Shows 30 seconds after the player joins, to that player only, and reminds spectators about `!join`.
- It is not repeated on map change, only after the player leaves and comes back.
- To change the text, edit the messages in the `.sp` and recompile.

### Requirements
- SourceMod 1.12 or newer and Metamod:Source
- Left 4 Dead 2

### Installation
1. Copy the `addons` folder from here into the game folder on the server (`<server-folder>/left4dead2/`), merging with the existing one.
2. Restart the server or run `sm plugins load skynet_welcome_l4d2` in the console.
