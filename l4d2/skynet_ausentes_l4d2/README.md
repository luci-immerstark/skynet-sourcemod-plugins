# SKYNET Idle-Proof Game / Jogo com Ausentes

**Left 4 Dead 2** · v1.0 · `skynet_ausentes_l4d2.smx`

[All plugins](../../README.md)

The match keeps going when every player goes idle.

## What it does
- By default the game ends the match when no human controls a survivor. With this plugin, bots hold the match while anyone is connected.
- With the server empty it goes back to normal so the server can hibernate.
- Pair it with **AFK** to kick players who stay idle too long.

## Requirements
- SourceMod 1.12 or newer and Metamod:Source
- Left 4 Dead 2

## Installation
1. Copy the `addons` folder from here into the game folder on the server (`<server-folder>/left4dead2/`), merging with the existing one.
2. Restart the server or run `sm plugins load skynet_ausentes_l4d2` in the console.
