# SKYNET No !map / Sem !map

**Left 4 Dead 2** · v1.0 · `skynet_sem_map_l4d2.smx`

[Português](#português) · [English](#english) · [Todos os plugins / All plugins](../../README.md)

## Português

Bloqueia `!map` e `!votemap` no jogo; a troca de campanha fica pelo menu de admin.

### O que faz
- O `sm_map` troca de mapa sem a abertura da campanha e com o nome em código. O plugin bloqueia esses comandos para jogadores e admins no jogo.
- O console do servidor (rcon) continua podendo usar.
- Combine com o **Próxima Campanha**, que tem a troca de campanha no menu de admin.

### Requisitos
- SourceMod 1.12 ou mais novo e Metamod:Source
- Left 4 Dead 2

### Instalação
1. Copie a pasta `addons` desta pasta para dentro da pasta do jogo no servidor (`<pasta-do-servidor>/left4dead2/`), juntando com a que já existe.
2. Reinicie o servidor ou digite `sm plugins load skynet_sem_map_l4d2` no console.

## English

Blocks `!map` and `!votemap` in game; campaign changes go through the admin menu.

### What it does
- `sm_map` changes level without the campaign intro and shows code names. The plugin blocks these commands for players and admins in game.
- The server console (rcon) can still use them.
- Pair it with **Next Campaign**, which adds campaign switching to the admin menu.

### Requirements
- SourceMod 1.12 or newer and Metamod:Source
- Left 4 Dead 2

### Installation
1. Copy the `addons` folder from here into the game folder on the server (`<server-folder>/left4dead2/`), merging with the existing one.
2. Restart the server or run `sm plugins load skynet_sem_map_l4d2` in the console.
