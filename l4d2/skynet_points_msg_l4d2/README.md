# SKYNET Points Messages

**Left 4 Dead 2** · v1.0 · `skynet_points_msg_l4d2.smx`

[Português](#português) · [English](#english) · [Todos os plugins / All plugins](../../README.md)

## Português

Mensagens de pontos e de compras do Points System em português.

### O que faz
- Mostra cada ganho de pontos com o motivo traduzido e o saldo: `[PONTOS] Matou Hunter +5 | Saldo: 120`.
- Mostra as compras com o item, o custo e o saldo, e avisa quem recebeu um item comprado por outro jogador.
- Para não repetir as mensagens, desligue as mensagens originais do Points System com `l4d2_points_notify 0`.

### Requisitos
- SourceMod 1.12 ou mais novo e Metamod:Source
- Left 4 Dead 2
- [Points System API](https://github.com/eyal282/l4d2-point-system-api) (Eyal282)

### Instalação
1. Copie a pasta `addons` desta pasta para dentro da pasta do jogo no servidor (`<pasta-do-servidor>/left4dead2/`), juntando com a que já existe.
2. Reinicie o servidor ou digite `sm plugins load skynet_points_msg_l4d2` no console.

## English

Portuguese messages for Points System earnings and purchases.

### What it does
- Shows every point gain with a translated reason and the balance: `[PONTOS] Matou Hunter +5 | Saldo: 120`.
- Shows purchases with item, cost and balance, and tells the player who received an item bought by someone else.
- To avoid duplicate messages, turn off Points System's own messages with `l4d2_points_notify 0`.

### Requirements
- SourceMod 1.12 or newer and Metamod:Source
- Left 4 Dead 2
- [Points System API](https://github.com/eyal282/l4d2-point-system-api) (Eyal282)

### Installation
1. Copy the `addons` folder from here into the game folder on the server (`<server-folder>/left4dead2/`), merging with the existing one.
2. Restart the server or run `sm plugins load skynet_points_msg_l4d2` in the console.
