# SKYNET Bot Names

**Team Fortress 2** · v1.1 · `skynet_botnames.smx`

[Português](#português) · [English](#english) · [Todos os plugins / All plugins](../../README.md)

## Português

Nomes fixos para os bots e chat limpo nas entradas e saídas deles.

### O que faz
- Cada bot recebe um nome da lista do plugin (edite a lista no `.sp`).
- Esconde do chat as mensagens de entrada, saída e troca de nome dos bots.
- Esconde o aviso `Server cvar 'tf_bot_count' changed`, que aparece a cada bot que entra ou sai.

### Requisitos
- SourceMod 1.12 ou mais novo e Metamod:Source
- Team Fortress 2

### Instalação
1. Copie a pasta `addons` desta pasta para dentro da pasta do jogo no servidor (`<pasta-do-servidor>/tf/`), juntando com a que já existe.
2. Reinicie o servidor ou digite `sm plugins load skynet_botnames` no console.

## English

Fixed names for bots and a clean chat when they join and leave.

### What it does
- Each bot gets a name from the plugin's list (edit the list in the `.sp`).
- Hides bot join, leave and name-change messages from chat.
- Hides the `Server cvar 'tf_bot_count' changed` notice that shows every time a bot joins or leaves.

### Requirements
- SourceMod 1.12 or newer and Metamod:Source
- Team Fortress 2

### Installation
1. Copy the `addons` folder from here into the game folder on the server (`<server-folder>/tf/`), merging with the existing one.
2. Restart the server or run `sm plugins load skynet_botnames` in the console.
