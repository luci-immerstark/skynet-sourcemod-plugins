# SKYNET Silence

**Team Fortress 2** · v1.0.0 · `skynet_silencio.smx`

[All plugins](../../README.md)

Hides the "Server cvar 'x' changed to y" messages from players' chat.

## What it does
- Useful when plugins change settings during the game (like the ghost mode speed of some FF2 bosses).
- The server log stays the same.

## Requirements
- SourceMod 1.12 or newer and Metamod:Source
- Team Fortress 2

## Installation
1. Copy the `addons` folder from here into the game folder on the server (`<server-folder>/tf/`), merging with the existing one.
2. Restart the server or run `sm plugins load skynet_silencio` in the console.
