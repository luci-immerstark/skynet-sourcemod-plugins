# SKYNET Pyro Only

**Team Fortress 2** · v1.0 · `skynet_pyroonly.smx`

[Português](#português) · [English](#english) · [Todos os plugins / All plugins](../../README.md)

## Português

Para servidores de Dodgeball: todo mundo joga de Pyro.

### O que faz
- Ao entrar num time, o jogador vira Pyro sozinho, sem abrir o menu de classes.
- Qualquer tentativa de trocar para outra classe é recusada.

### Requisitos
- SourceMod 1.12 ou mais novo e Metamod:Source
- Team Fortress 2 (servidor de Dodgeball)

### Instalação
1. Copie a pasta `addons` desta pasta para dentro da pasta do jogo no servidor (`<pasta-do-servidor>/tf/`), juntando com a que já existe.
2. Reinicie o servidor ou digite `sm plugins load skynet_pyroonly` no console.

## English

For Dodgeball servers: everyone plays Pyro.

### What it does
- When joining a team the player becomes Pyro automatically, without the class menu.
- Any attempt to switch to another class is refused.

### Requirements
- SourceMod 1.12 or newer and Metamod:Source
- Team Fortress 2 (Dodgeball server)

### Installation
1. Copy the `addons` folder from here into the game folder on the server (`<server-folder>/tf/`), merging with the existing one.
2. Restart the server or run `sm plugins load skynet_pyroonly` in the console.
