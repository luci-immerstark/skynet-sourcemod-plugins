# SKYNET Terceira Pessoa

**Team Fortress 2** · v1.0.0 · `skynet_terceira.smx`

[Português](#português) · [English](#english) · [Todos os plugins / All plugins](../../README.md)

## Português

`!tp` para jogar em terceira pessoa e `!fp` para voltar.

### O que faz
- `!tp` liga ou desliga a câmera em terceira pessoa (a mesma câmera das taunts).
- `!fp` volta para a primeira pessoa.
- A escolha continua depois de morrer e nascer de novo, até o jogador sair do servidor.
- Não precisa de `sv_cheats`.

### Requisitos
- SourceMod 1.12 ou mais novo e Metamod:Source
- Team Fortress 2

### Instalação
1. Copie a pasta `addons` desta pasta para dentro da pasta do jogo no servidor (`<pasta-do-servidor>/tf/`), juntando com a que já existe.
2. Reinicie o servidor ou digite `sm plugins load skynet_terceira` no console.

### Comandos
| Comando | Acesso | Descrição |
|---|---|---|
| `sm_tp` / `!tp` (ou `sm_thirdperson`) | todos | Liga/desliga a terceira pessoa |
| `sm_fp` / `!fp` (ou `sm_firstperson`) | todos | Volta para a primeira pessoa |

## English

`!tp` to play in third person and `!fp` to go back.

### What it does
- `!tp` toggles the third-person camera (the same camera used by taunts).
- `!fp` goes back to first person.
- The choice stays after dying and respawning, until the player leaves the server.
- No `sv_cheats` needed.

### Requirements
- SourceMod 1.12 or newer and Metamod:Source
- Team Fortress 2

### Installation
1. Copy the `addons` folder from here into the game folder on the server (`<server-folder>/tf/`), merging with the existing one.
2. Restart the server or run `sm plugins load skynet_terceira` in the console.

### Commands
| Command | Access | Description |
|---|---|---|
| `sm_tp` / `!tp` (or `sm_thirdperson`) | everyone | Toggles third person |
| `sm_fp` / `!fp` (or `sm_firstperson`) | everyone | Goes back to first person |
