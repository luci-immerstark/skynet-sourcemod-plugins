# SKYNET Welcome

**Team Fortress 2** · v1.1 · `skynet_welcome.smx`

[Português](#português) · [English](#english) · [Todos os plugins / All plugins](../../README.md)

## Português

Mensagem de boas-vindas no chat, uma vez por conexão.

### O que faz
- Aparece 30 segundos depois de o jogador entrar, só para ele.
- Não repete na troca de mapa. Só aparece de novo se o jogador sair e voltar.
- Para mudar o texto, edite a mensagem no `.sp` e compile de novo.

### Requisitos
- SourceMod 1.12 ou mais novo e Metamod:Source
- Team Fortress 2

### Instalação
1. Copie a pasta `addons` desta pasta para dentro da pasta do jogo no servidor (`<pasta-do-servidor>/tf/`), juntando com a que já existe.
2. Reinicie o servidor ou digite `sm plugins load skynet_welcome` no console.

## English

Welcome message in chat, once per connection.

### What it does
- Shows 30 seconds after the player joins, to that player only.
- It is not repeated on map change, only after the player leaves and comes back.
- To change the text, edit the message in the `.sp` and recompile.

### Requirements
- SourceMod 1.12 or newer and Metamod:Source
- Team Fortress 2

### Installation
1. Copy the `addons` folder from here into the game folder on the server (`<server-folder>/tf/`), merging with the existing one.
2. Restart the server or run `sm plugins load skynet_welcome` in the console.
